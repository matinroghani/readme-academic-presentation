# ارائه دانشگاهی: مستندسازی نرم‌افزار و README

یک ارائه‌ی فارسی، راست‌به‌چپ و بدون وابستگی خارجی برای درس «روش تحقیق و گزارش‌نویسی»؛ با تمرکز بر مستندسازی نرم‌افزار، نگارش README و آموزش پایه Markdown.

## اجرا

1. پوشه پروژه را استخراج کنید.
2. فایل `index.html` را در مرورگر باز کنید.
3. برای استفاده از تمام‌صفحه، روی «تمام‌صفحه» کلیک کنید. برنامه بدون نصب پکیج یا سرور توسعه اجرا می‌شود.

## امکانات

- ۲۰ اسلاید با زمان‌بندی پیشنهادی مجموعاً ۲۰ دقیقه
- جابه‌جایی با دکمه‌های قبلی و بعدی یا کلیدهای جهت‌دار
- شروع و مکث زمان‌سنج کل و اسلاید
- نمایش تمام‌صفحه و یادداشت‌های ارائه‌دهنده
- مثال‌های Markdown با نمایش مورد انتظار
- کپی مثال‌ها و دانلود نمونه کامل `README.md`
- چک‌لیست تعاملی ارزیابی README
- طراحی واکنش‌گرا برای نمایشگرهای کوچک

## میان‌برهای صفحه‌کلید

- `→` یا `Page Down`: اسلاید بعدی
- `←` یا `Page Up`: اسلاید قبلی
- `Home`: رفتن به اسلاید اول
- `End`: رفتن به اسلاید آخر
- `Space`: شروع یا مکث زمان‌سنج
- `F`: نمایش یا خروج از تمام‌صفحه
- `N`: نمایش یا پنهان کردن یادداشت‌های ارائه‌دهنده

## ساختار فایل‌ها

```text
readme-academic-presentation/
├── index.html
├── README.md
└── assets/
    ├── css/
    │   └── styles.css
    └── js/
        ├── app.js
        └── slides.js
```

## ویرایش محتوا

- فراداده‌ی اسلایدها، زمان‌بندی، منابع و متن یادداشت‌ها در `assets/js/slides.js` قرار دارد.
- ساختار محتوایی و رفتارهای تعاملی اسلایدها در `assets/js/app.js` است.
- رنگ‌ها، فاصله‌ها، تایپوگرافی و واکنش‌گرایی در `assets/css/styles.css` تعریف شده‌اند.
- در اسلاید عنوان، مقادیر «نام دانشجو»، «نام استاد»، «نام دانشگاه» و «نیم‌سال تحصیلی» را با اطلاعات ارائه جایگزین کنید.
- مثال‌های `USERNAME`، `python main.py` و مجوز MIT در README نمونه، مقادیر آموزشی هستند و برای پروژه‌ی واقعی باید بررسی و اصلاح شوند.

## نکته درباره زمان‌سنج

مجموع زمان‌های پیشنهادی ۱۲۰۰ ثانیه است. جابه‌جایی دستی بین اسلایدها زمان باقی‌مانده‌ی کل را متوقف یا بازتنظیم نمی‌کند؛ زمان همان اسلاید با زمان پیشنهادی آن اسلاید بازنشانی می‌شود. زمان‌سنج، ابزار کمکی ارائه است و با عبور از ۲۰ دقیقه متوقف می‌شود.
